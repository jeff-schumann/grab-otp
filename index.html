🔐 Grab OTP

Automatically retrieve OTP codes from Gmail based on your current website's domain

✨ Features

  • Auto OTP Detection - finds verification codes in Gmail emails
  • Clipboard Copy - automatically copies codes for easy pasting
  • Auto-Fill - fills codes directly into website forms (Chrome)
  • Security First - minimal permissions, OAuth 2.0, no data logging
  • Cross-Browser - works on Chrome and Firefox

🚀 Installation

Grab OTP is designed for personal use and open-source distribution. You can build it from source or download pre-built releases from GitHub.

See the installation guide for detailed instructions on building and loading the extension in your browser.

🛡️ Privacy & Security

OTP extraction happens locally in your browser. Grab OTP contacts Google for Gmail/OAuth and GitHub for update checks, but does not run analytics, ads, or a developer-controlled backend.
